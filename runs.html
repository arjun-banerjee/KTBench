Column glossary

scenario
Ensemble scenario name. ktbench.<problem> is the single-agent shape; ktbench.judge_<problem> spawns an author plus a code_reviewer reviewer and is the multi-actor cell.
persona
Persona TOML the agent was framed with (translator baseline, methodical engineer, speed obsessed, etc.). Lives under integrations/ensemble/personas/.
problem / axis
The problem id and the <src_dsl> → <tgt_dsl> translation axis.
outcome
passed = submit landed with a non-zero final score. failed = submit landed but a gate (correctness, stress, utilisation) zeroed the score. incomplete = the agent never reached submit_kernel before the turn budget or scheduler quiescence stopped the run.
final
Headline KTBench score for this run: correctness_rate × stress_pass_rate × sol_score, in [0, 1].
SOL
Speed-of-Light fraction: max(achieved_throughput / hw_peak_throughput) across the compute and memory axes. Bounded by physics, not by the reference baseline. Computed from per-problem perf.py::flops() (compute axis) and the input + output tensor byte totals (memory axis).
speedup
Candidate's mean runtime divided by the handwritten reference_tgt.py baseline runtime on the same inputs. Reported but not part of the gated score because it is gameable by slowing the reference.
gpu-seconds
Accelerator wall-clock for the eval pipeline (compile, correctness suite, stress, timing). Excludes scheduler idle time and LLM latency.
trace
Opens the per-run viewer with every tool call, tool result, reasoning summary, and grader output for this cell.
